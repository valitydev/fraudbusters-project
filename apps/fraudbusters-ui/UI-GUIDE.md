## Основа

`src/app/styles/_tokens.scss` — источник цветовых, типографических и размерных токенов. Светлая и тёмная темы используют одинаковые роли. В компонентах применяйте токены по назначению: `--fb-canvas` для фона страницы и полей, `--fb-surface` для панелей и полей в фокусе, `--fb-raised` для выделенных областей, `--fb-line` для границ, `--fb-muted` для вторичного текста, `--fb-accent` для акцента и фокуса. Светлая тема использует фиолетовый `#6338F5` и фон `#F8F9FB`. Значения взяты из прототипов аналитики и истории, где уже совпадают основные цвета.

| Роль                  | Размер и начертание | Где применять                                                                           |
| --------------------- | ------------------- | --------------------------------------------------------------------------------------- |
| Заголовок страницы    | Inter 22/28, 600    | Один `h1.fb-page-title` на экран.                                                       |
| Описание страницы     | Inter 14/20, 400    | `p.fb-page-subtitle` под заголовком.                                                    |
| Заголовок панели      | Inter 14/20, 600    | `.fb-section-title` на заголовке нужного уровня.                                        |
| Поле                  | 13/20, 400          | Inter для обычного текста и поиска. JetBrains Mono для ID, кодов, чисел в полях и даты. |
| Код и данные          | JetBrains Mono      | Fraudo, CSV, идентификаторы и числовые значения KPI.                                    |
| Вспомогательный текст | Inter 12–13         | Подписи, подсказки, состояние и сводка таблицы.                                         |

Граница панели — 1 px, радиус — 12 px. Радиус полей и кнопок — 8 px. Основные интервалы между связанными элементами — 8 px, между полями — 12–16 px, внутри панели — 16–24 px. Таблицы прокручиваются внутри своей области, панели фильтров переносят элементы по ширине.

## Типографика таблиц

Эталон плотности — **Historical data → Inspect results**. Все таблицы интерфейса используют ту же шкалу через `.fb-catalog-table`. Сюда входят каталоги платежей и выплат, кандидаты, аудит, уведомления, тестовые наборы, очереди добавления и предпросмотр CSV. Таблица правил в Analytics использует те же токены для своей сетки.

| Элемент                           | Размер и высота строки | Шрифт                                                     |
| --------------------------------- | ---------------------- | --------------------------------------------------------- |
| Заголовок колонки                 | 11/16 px               | Inter, прописные буквы                                    |
| Обычная ячейка и вкладка каталога | 13/18 px               | Inter, обычный межбуквенный интервал                      |
| ID, код и превью Fraudo           | 12/18 px               | JetBrains Mono, обычный межбуквенный интервал             |
| Дата и время                      | 12/18 px               | Inter, цифры одинаковой ширины                            |
| Кнопка в строке                   | 12 px                  | Inter, обычный межбуквенный интервал, высота кнопки 32 px |

Размеры задаёт `styles/_data-table.scss` через токены `--fb-table-*`. Используйте `code` или `.fb-catalog-mono` для технических значений и `.fb-catalog-time` для даты. В локальных стилях задавайте ширину и перенос колонок. Длинное превью правила остаётся в одну строку с многоточием. Полный текст доступен при раскрытии строки. Размер заголовка страницы и шрифт редактора Fraudo задаются отдельно по своим ролям.

Основная ячейка строки сохраняет семантику `th scope="row"` и получает начертание 500 через `.fb-catalog-row-label`, как в Inspect results. Применяйте его к имени набора и ID в результатах Testing. Заголовки панелей Test results и Rule expression используют `.fb-section-title` (14/20 px, 600).

Ссылки на ID в таблицах используют `.fb-catalog-link.fb-catalog-mono`. В обычном состоянии это акцентный текст 12/18 px. Подчёркивание появляется при наведении и клавиатурном фокусе. При фокусе виден контур. Сохраняйте семантику и адрес перехода ссылки.

При проверке сравнивайте **заполненные** таблицы с Inspect results при одном масштабе браузера. Проверьте шрифт ID, даты, превью и кнопок в вычисленных стилях. На узком экране таблица прокручивается внутри панели.

## Геометрия таблиц

Одна шкала для каталогов платежей и выплат, истории, Testing, уведомлений и аудита. Размеры заданы токенами `--fb-table-*` и `--fb-row-control-height`.

| Элемент               | Размер                                                                     |
| --------------------- | -------------------------------------------------------------------------- |
| Заголовок таблицы     | Минимум 37 px, по 10 px сверху и снизу для текстовых ячеек                 |
| Строка данных         | Минимум 56 px, по 8 px сверху и снизу                                      |
| Ячейки                | По 12 px по горизонтали, по 20 px у внешних краёв таблицы                  |
| Действия в строке     | Высота 32 px, промежуток 8 px между кнопками, выравнивание по правому краю |
| Панель над таблицей   | 14 px по вертикали и 20 px по горизонтали                                  |
| Нижняя панель таблицы | Минимум 44 px, отступы 4 px по вертикали и 20 px по горизонтали            |

Обычные заголовки колонок помещаются в одну строку. Если заголовок переносится, выделите ему достаточную ширину. В Grey статус и период располагаются рядом и могут переноситься при длинных значениях. Длинные значения могут увеличить высоту строки. В Lists значение обрезается многоточием, полный текст доступен при наведении и через Copy. Раскрытые детали имеют собственную высоту по содержимому. Панель с фильтрами может стать выше при переносе полей или появлении подписей. Ширину колонок задаёт содержимое и назначение таблицы. Сохраняйте горизонтальную прокрутку внутри панели.

При сверке измеряйте по одной заполненной строке при одинаковом масштабе браузера, в том числе в выплатах. Проверьте отступы обычной, первой и последней ячеек и высоту кнопки меню.

## Переиспользование

| Элемент         | Что использовать                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Страница        | `.fb-page` — колонка блоков страницы с интервалом 24 px, `.fb-page-catalog` уменьшает его до 8 px у каталогов. `.fb-page-header` — строка с кнопкой возврата и заголовком. Flex Layout (`fxLayout`) не используется.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Панель          | `@include primitives.panel` из `styles/_primitives.scss`. Каталог открывайте через `fb-catalog-panel`, таблицу — через `.fb-catalog-scroll` и `.fb-catalog-table`. Для существующих раскрывающихся списков используйте `.fb-data-table`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Поля и селекты  | Для простых полей и `mat-select` используйте `.fb-filter-control` (36 px) или `.fb-form-control` (40 px). Добавляйте `.fb-control-mono` для идентификаторов и значений даты. Оба токена увеличиваются до 44 px при грубом указателе. Для полей Angular Material с плавающей меткой используйте `.fb-filter-fields`.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Состояния полей | У каждого поля есть видимая подпись и доступное имя. Фокус использует фиолетовую границу и цвет поверхности. Ошибки связываются с полем через `aria-invalid` и `aria-describedby`, когда у поля есть видимый текст ошибки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Поиск           | `fb-catalog-search` — поиск в каталоге с иконкой и клавишей `/`. Использует высоту фильтра.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Дата и время    | `fb-datetime-range` для нового календаря. `.form-range` применяет высоту поля формы. Сохраняйте подписи From/To, часовой пояс и существующую семантику применения периода.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Действия        | `.fb-primary-action` для выделенного действия в шапке каталога, `.fb-template-back` для возврата, `.fb-row-actions` или `.fb-catalog-row-actions` для действий строки. Высота компактных действий — 32 px. Кнопке с одной иконкой требуется доступное имя.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Меню и списки   | Все `mat-menu`, `mat-select` и `mat-autocomplete` оформлены глобально, `panelClass` не нужен: панель с радиусом 12 px, Inter 13/20, строка 36 px, иконка 18 px приглушённого цвета, выбранный вариант — акцентный текст на `--fb-selected`. Удаление в меню помечайте `.fb-menu-danger`. У пунктов `type="button"`.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Загрузка        | `mat-progress-bar mode="indeterminate"` на краю панели. Он и любой элемент с `.fb-delayed-loader` (текст «Loading…», скелет) появляются через 300 мс (`--fb-loader-delay`), чтобы быстрые операции не мигали.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Статус          | `.fb-pill` и соответствующий тон `success`, `info`, `warning`, `danger`, `accent` или нейтральный. `.fb-pill-status` добавляет точку и моноширинный текст. Цвет точки списка дублируется текстом Black, White, Grey или Candidates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Формы настроек  | `fb-create-notification` и `fb-create-channel`: шапка с `.fb-template-back`, панель с разделами `.fb-section-title`, поля `.fb-form-control` с подписью и подсказкой, футер со статусом, **Cancel** и **Create**/**Save**. Обязательные поля помечены `*`, ошибка сохранения выводится в футере.                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Редакторы и CSV | Переиспользуйте редакторы и `fb-csv-panel` для платежей и выплат. Поля и допустимые значения определяет сценарий.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Проверки Fraudo | `fb-fraudo-editor` подсвечивает ошибки до серверной валидации: непарные скобки, незакрытую строку, неизвестную функцию, результат или поле (в том числе в группировке), недопустимый результат после `catch:`, правило без `->` или `;`, а также пару скобки у курсора. Поля проверяются по типу шаблона (`[dialect]`: payment или payout), для выплат также запрещены `3ds`, `isTrusted`, `isMobile` и `isRecurrent`. Поля, которые сервер разрешает только при наличии истории, проверяет Validate. Первая ошибка показывается в строке статуса. Функции, результаты и поля генерируются из грамматики и enum полей fraudbusters: `npm run fraudo-codegen` (входит в `codegen`). Какие аргументы являются полями, описано в `fraudo-field-arguments.ts`. |

В каталогах групп платежей и выплат показывайте первый шаблон по порядку выполнения и количество остальных. Полный состав, порядок и веса доступны по кнопке **Edit**.

## Проверка экранов

| Зона                                                                                                 | Что сверять при изменениях                                                                                                                      |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Analytics и Historical data                                                                          | Высоту полей, пресетов и календаря, активный период, результаты, пустое состояние и ошибку.                                                     |
| Templates, References, Lists, Candidates                                                             | Заголовок, вкладки, поиск, сортировку, состояния таблицы, раскрытие строк и действия. Повторить для платежей и выплат, где доступны оба режима. |
| Groups                                                                                               | Превью первого шаблона, количество остальных и переход по **Edit** к составу группы. Повторить для платежей и выплат.                           |
| New/Edit template, New/Edit group, New references, New rows, New/Edit notification, New/Edit channel | Поля и доступные имена, фокус, подсказки, ошибки, действия с добавляемыми строками и CSV. Проверить доступные варианты цели и редактирования.   |
| Audit, Testing, Notifications, Channels, Load fraud                                                  | Общую типографику, элементы поиска, стили кнопок и состояний.                                                                                   |

1. Откройте затронутые маршруты с данными, пустым результатом и ошибкой. Сверьте одинаковые элементы в соседних разделах.
2. Проверьте светлую и тёмную темы, десктоп и ширину 390 px. На узком экране проверьте перенос полей и прокрутку таблиц внутри панели.
3. Пройдите поиск, календарь, меню и кнопки клавишами Tab, Enter и Escape. Проверьте видимость фокуса и возврат из всплывающей панели.
4. Запустите `npm run ui:check`, `npm run ui:test` и сборку UI. Сценарии с данными можно проверять на локальных фикстурах.
5. Если интерфейс открыт через Docker на `localhost:8989`, после сборки обновите контейнер UI и сверьте имена CSS и JS в HTML, который отдаёт этот адрес, с новым `index.html`. Сверьте вычисленные стили на этом же адресе.

## Результат сверки

-   На 36 маршрутах Chrome подтвердил применение заголовка страницы. На маршрутах с контрольными полями сверены базовая высота, радиус, фон и граница фокуса.
-   На семи маршрутах проверены ширина 390 px, отсутствие горизонтальной прокрутки страницы, цвет заголовка в тёмной теме и радиус панелей.
-   В истории проверены сенсорная высота 44 px, раскрытие дополнительных фильтров, фокус в тёмной теме и закрытие календаря клавишей Escape.
-   Браузерная проверка использовала локальные ответы API и тестовые данные.
-   Типографика проверена в 23 заполненных сценариях, включая каталоги, Inspect results, очереди добавления, предпросмотр CSV, эмуляцию и таблицу правил Analytics. Для 17 маршрутов также проверено, что на ширине 390 px таблица помещается в область прокрутки без расширения страницы.
