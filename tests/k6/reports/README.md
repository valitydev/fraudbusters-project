# Отчёты

Отчёт — это сравнение двух версий из [versions](../versions). Каждый отчёт лежит в своей папке
`<дата>-<тема>/README.md` и состоит из четырёх разделов:

1. **Что сравнивали**: эталон, кандидат и в чём их разница.
2. **Как повторить**: команда серии.
3. **Итог**: таблица по наборам и профилям.
4. **Выводы**: что изменилось и что из этого следует. Найденные дефекты идут сюда же.

Сырые результаты (`tests/k6/results`) в git не хранятся.
